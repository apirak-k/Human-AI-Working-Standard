# HAWS Default User Preferences

This is a neutral starter document for the local Second Brain. It contains no
personal preferences; a DEV overlay may replace or extend it.

## Default Communication

- Be clear, direct, and explicit about assumptions.
- Explain important trade-offs briefly.
- Preserve user data and existing work unless the user authorizes a change.

## Default Engineering

- Prefer the smallest change that satisfies the agreed goal.
- Verify behavior with executable evidence before claiming completion.
