# Repository Instructions

This repository uses HAWS. Before changing files, read `core/HAWS.md`, `core/WORK_INSTRUCTIONS.md`, and `PROJECT_SPECIFIC.md`. When continuing existing work, read `HANDOFF.md` and verify the actual repository, branch, and worktree state first.

`AGENTS.md`, `PROJECT_SPECIFIC.md`, and `HANDOFF.md` are development instructions and continuation records; keep them on `dev` only. `PROJECT_SPECIFIC.md` is the source of truth for synchronizing completed HAWS code and user-facing documentation from `dev` to `main`.
