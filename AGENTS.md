# Repository Instructions

This repository uses HAWS. Before changing files, read `core/HAWS.md`, `core/WORK_INSTRUCTIONS.md`, and `PROJECT_SPECIFIC.md`. When continuing existing work, read `HANDOFF.md` when it exists in the current checkout and verify the actual repository, branch, and worktree state first.

`PROJECT_SPECIFIC.md` is shared by `dev` and `main` and is the source of truth for branch synchronization and documentation routing. Completed, verified work pushed to `dev` must also be synchronized to `main` in the same task. Keep only continuation documents such as `HANDOFF.md` and unfinished plans on `dev`.
