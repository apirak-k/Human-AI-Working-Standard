# HAWS Project Blueprint Templates

This directory contains standardized templates for scaffolding and managing individual software projects under the Human-AI Working Standard (HAWS).

---

## 📁 Canonical Template Suite

| Template | File | Purpose |
| :--- | :--- | :--- |
| **Project & Roadmap** | PROJECT.md | Scope boundaries (In-scope vs Non-goals), tech stack, and delivery roadmap. |
| **System Ground Truth** | SOT.md | Authoritative verified ground truth of live architecture, data contracts, and solved invariant lessons. |
| **Agent Guardrails** | AGENTS.md | Agent roles, permissions matrix, strictly forbidden actions, and project anti-patterns. |
| **Design System** | DESIGN.md | UI design tokens, color palette, typography, responsive guidelines, and WCAG AA rules. |
| **Session Checkpoint** | HANDOFF.md | Inter-session checkpoint, active task checklists, unverified areas, and exact resume points. |
| **Quality Contracts** | CONSTRAINTS.md | Non-negotiable quality gates: coverage thresholds, linter rules, and verification runners. |
